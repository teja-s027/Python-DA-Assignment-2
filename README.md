Python Data Analysis – Assignment 2

Data Visualization

This project focuses on data visualization using Python. The analysis is performed using the Seaborn "taxis" dataset.

Tools and Libraries

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

Dataset

The project uses the "taxis" dataset available through Seaborn.

Data Preparation

The dataset was checked for missing values, and missing categorical values were handled using appropriate imputation.

Visualizations

The following visualizations are included:

Matplotlib / Pandas

- Line Chart – Fare over time
- Bar Chart – Total fare by pickup borough
- Pie Chart – Trips by payment method
- Histogram – Distribution of distance
- Box Plot – Tip amounts by pickup borough

Seaborn

- Count Plot – Number of trips by pickup borough
- Scatter Plot – Distance vs Fare
- Heatmap – Correlation between numerical variables
- Pair Plot – Pairwise relationships between distance, fare, tip, and total
- Violin Plot – Fare distribution by payment method

Project File

"Python_DA_Assignment_2_Data_Visualization.ipynb"

Objective

The objective of this assignment is to explore the dataset and understand different patterns and relationships through data visualization.
